# Xoshi XI v3

Autonomous X agent focused on $XOSHI, tokenized stocks, Stock Tokens, RWAs, Robinhood Chain, DeFi, AI agents and onchain finance.

This build includes a stronger editorial identity: thesis, contrarian insight, second-order effects, micro-analysis and concise crypto-native replies instead of generic AI explanations.

The Playwright agent uses direct X composer navigation (`/compose/post`) plus click/force-click/DOM/keyboard fallbacks.

Required GitHub Actions secrets: FASTAPI_URL, TWITTER_AUTH_TOKEN, TWITTER_CT0, GROQ_API_KEY, GEMINI_API_KEY. GIST_ID/GIST_TOKEN are retained as optional compatibility variables.

Never commit credentials or browser profiles.
